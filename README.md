# T-System: Многофункциональное приложение с Telegram ботом

Проект представляет собой комплексную систему, включающую Telegram бота, веб-серверы на Express/Fastify и интеграцию с Google Sheets API.

## 🏗️ Архитектура проекта

```
src/
├── apis/                    # API интеграции
│   ├── google-sheets/      # Клиент Google Sheets API
│   └── m-chat/            # Чат-система (в разработке)
├── bots/                   # Telegram боты
│   ├── tg/                # Основной Telegram бот
│   └── max/               # Дополнительный бот
├── helpers/                # Вспомогательные утилиты
├── rag/                    # RAG система для поиска по коду
├── server/                 # Веб-серверы
│   ├── express/           # Express сервер
│   └── fastify/           # Fastify сервер
└── webapps/               # Веб-приложения
```

## 🚀 Основные компоненты

### 1. Telegram Bot (`src/bots/tg/`)
- **Функционал**: Обработка команд и сообщений пользователей
- **Интеграции**: Google Sheets для хранения данных
- **Команды**:
  - `/start` - Приветствие
  - `/help` - Справочная информация
  - Любой текст - Запись в Google Sheets и возврат данных

### 2. Google Sheets API (`src/apis/google-sheets/`)
- **Аутентификация**: JWT 2.0 с сервисным аккаунтом
- **Функционал**: Чтение/запись данных в таблицы
- **Кэширование**: Токенов доступа для оптимизации

### 3. Express Server (`src/server/express/`)
- **REST API**: CRUD операции для элементов
- **Эндпоинты**:
  - `GET /api/items` - Получение всех элементов
  - `GET /api/items/:id` - Получение элемента по ID
  - `POST /api/items` - Создание элемента
  - `PUT /api/items/:id` - Обновление элемента
  - `DELETE /api/items/:id` - Удаление элемента

### 4. Fastify Server (`src/server/fastify/`)
- **Современный альтернативный сервер**
- **Плагины**: CORS, Swagger, валидация окружения
- **Схемы**: JSON Schema для валидации данных

### 5. RAG Система (`src/rag/`)
- **Назначение**: Семантический поиск по коду проекта
- **Функционал**:
  - Индексация всех TypeScript файлов
  - Векторизация кода
  - Поиск по смысловым запросам на русском языке
- **Использование**: Помощь в навигации по кодовой базе

## 🛠️ Технологический стек

### Основные зависимости
- **Telegram**: `telegraf` - фреймворк для Telegram ботов
- **Веб-серверы**: `express`, `fastify` - HTTP фреймворки
- **Google API**: Встроенный JWT клиент для Google Sheets
- **Даты**: `dayjs` - работа с датами и временем
- **Окружение**: `dotenv` - управление переменными окружения

### Инструменты разработки
- **TypeScript**: `typescript`, `ts-node` - типизация и компиляция
- **Линтинг**: `eslint`, `prettier` - качество кода
- **Отслеживание**: `nodemon` - автоматический перезапуск

## 📦 Установка и запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <repository-url>
cd t-system
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:
```env
TG_BOT_TOKEN=your_telegram_bot_token
GOOGLE_SHEETS_KEY=path/to/service-account-key.json
```

### 3. Запуск компонентов

#### Telegram бот
```bash
# Продуктивный режим
npm run bot

# Режим разработки с автоперезапуском
npm run bot-dev
```

#### Express сервер
```bash
# Продуктивный режим
npm run server-express

# Режим разработки
npm run server-express-dev
```

#### Fastify сервер
```bash
# Режим разработки
npm run server-fastify-dev
```

#### Линтинг кода
```bash
npm run lint
```

## 📚 API Документация

### Express API Endpoints

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/items` | Получение всех элементов |
| GET | `/api/items/:id` | Получение элемента по ID |
| POST | `/api/items` | Создание нового элемента |
| PUT | `/api/items/:id` | Обновление элемента |
| DELETE | `/api/items/:id` | Удаление элемента |

### Примеры запросов

#### Создание элемента
```bash
curl -X POST http://localhost:3000/api/items \
  -H "Content-Type: application/json" \
  -d '{"name": "Новый элемент"}'
```

#### Получение всех элементов
```bash
curl http://localhost:3000/api/items
```
