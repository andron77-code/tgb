# Инструкции для работы с проектом T-System

## 📋 Обзор проекта

T-System - это многофункциональный Node.js проект, включающий:
- Telegram бота для взаимодействия с пользователями
- Два веб-сервера (Express и Fastify) с REST API
- Интеграцию с Google Sheets API
- RAG систему для семантического поиска по коду
- Универсальный HTTP клиент (HTTPQuery)

## 🏗️ Архитектура проекта

### Структура директорий
```
src/
├── apis/                    # API клиенты
│   ├── google-sheets/       # Google Sheets API клиент
│   ├── m-chat/             # MasterChat клиент
│   └── http/               # Универсальный HTTP клиент
├── bots/                   # Telegram боты
│   ├── max/               # Дополнительный бот (в разработке)
│   └── tg/                # Основной Telegram бот
├── helpers/               # Утилиты и хелперы
├── server/                # Веб-серверы
│   ├── express/           # Express сервер
│   └── fastify/           # Fastify сервер
└── rag/                  # RAG система поиска
```

## 🔧 Ключевые компоненты

### 1. HTTPQuery (`src/apis/http/`)
**Назначение**: Универсальный HTTP клиент для всех API запросов

**Основные методы**:
- `get(url, options)` - GET запросы
- `post(url, options)` - POST запросы  
- `put(url, options)` - PUT запросы
- `delete(url, options)` - DELETE запросы
- `head(url, options)` - HEAD запросы

**Использование**:
```typescript
import { httpQuery } from '../http';

const response = await httpQuery.get('https://api.example.com/data', {
  headers: { 'Authorization': 'Bearer token' }
});
```

### 2. GoogleSheetsClient (`src/apis/google-sheets/`)
**Назначение**: Клиент для работы с Google Sheets API

**Ключевые методы**:
- `createTableSheetManager(spreadSheetId)` - Создание менеджера таблицы
- `getListData(listName)` - Чтение данных из листа
- `setListData(listName, data, range)` - Запись данных в лист

**Аутентификация**: JWT 2.0 с сервисным аккаунтом Google

### 3. MasterChat (`src/apis/m-chat/`)
**Назначение**: Клиент для чат-системы MasterChat

**Основной метод**:
- `query(message)` - Отправка сообщения и получение ответа

### 4. Telegram Bot (`src/bots/tg/`)
**Назначение**: Основной Telegram бот для взаимодействия с пользователями

**Команды**:
- `/start` - Приветствие
- `/help` - Справка
- Любой текст - Запись в Google Sheets и возврат данных

**Интеграции**:
- Google Sheets для хранения данных
- MasterChat (в планах)

### 5. Express Server (`src/server/express/`)
**Назначение**: REST API сервер на Express

**Эндпоинты**:
- `GET /api/items` - Получение всех элементов
- `GET /api/items/:id` - Получение элемента по ID
- `POST /api/items` - Создание элемента
- `PUT /api/items/:id` - Обновление элемента
- `DELETE /api/items/:id` - Удаление элемента

### 6. Fastify Server (`src/server/fastify/`)
**Назначение**: Альтернативный современный сервер

**Плагины**:
- CORS для кросс-доменных запросов
- Swagger для документации API
- Валидация окружения

### 7. RAG System (`src/rag/`)
**Назначение**: Семантический поиск по коду проекта

**Функционал**:
- Индексация всех TypeScript файлов
- Векторизация кода
- Поиск по смысловым запросам на русском языке

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Создать файл `.env` с переменными:
```
TG_BOT_TOKEN=your_telegram_bot_token
```

### 3. Запуск компонентов

**Telegram бот**:
```bash
npm run bot
# или для разработки
npm run bot-dev
```

**Express сервер**:
```bash
npm run server-express
# или для разработки
npm run server-express-dev
```

**Fastify сервер**:
```bash
npm run server-fastify-dev
```

**RAG система демонстрация**:
```bash
npx ts-node src/rag/demo.ts
```

## 📝 Кодирование и лучшие практики

### Стиль кода
- Используется TypeScript со строгой типизацией
- ESLint для линтинга
- Prettier для форматирования
- Русские комментарии в коде

### Структура классов
- Все классы экспортируются по умолчанию
- Приватные методы начинаются с `private`
- Подробные JSDoc комментарии на русском языке

### Обработка ошибок
- Глобальный обработчик ошибок в Express
- Консистентная обработка HTTP ошибок
- Логирование ошибок с временной меткой

### HTTP запросы
- Все HTTP запросы должны использовать класс HTTPQuery
- Аутентифицированные запросы включают Bearer токены
- Обработка статусов ответов и ошибок

## 🔍 Поиск по коду

Используйте RAG систему для семантического поиска:
```typescript
import { ragSystem } from './src/rag';

const results = await ragSystem.search('HTTPQuery класс методы');
```

## 🛠️ Разработка

### Добавление новых API клиентов
1. Создать директорию в `src/apis/`
2. Реализовать класс с использованием HTTPQuery
3. Добавить экспорт по умолчанию
4. Обновить RAG систему новыми поисковыми запросами

### Добавление новых эндпоинтов
1. Создать контроллер в `src/server/express/controllers/`
2. Добавить маршрут в `src/server/express/routes/`
3. Обновить документацию

### Тестирование
```bash
npm run lint  # Проверка кода
npx ts-node src/rag/demo.ts  # Тест RAG системы
```

## 🚨 Частые проблемы

### 1. Проблемы с Google Sheets API
- Убедитесь что ключ сервисного аккаунта валиден
- Проверьте доступы к таблице
- Проверьте квоты API

### 2. Проблемы с Telegram ботом
- Проверьте токен бота
- Убедитесь что бот запущен
- Проверьте вебхук (если используется)

### 3. Проблемы с HTTP запросами
- Используйте HTTPQuery вместо fetch
- Проверьте заголовки аутентификации
- Обрабатывайте статусы ответов
