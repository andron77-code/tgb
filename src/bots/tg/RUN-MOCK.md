# 🚀 Запуск Telegram бота с заглушками

## ✅ Готово к запуску!

Все компоненты бота работают с заглушками, нет необходимости в реальных базах данных.

## 📋 Что нужно сделать:

### 1. Настройте токен бота

Создайте файл `.env` в корне проекта:

```env
TG_BOT_TOKEN=your_telegram_bot_token
```

### 2. Запустите бота

```bash
# Простой запуск
npm run bot

# Запуск в режиме разработки (с авто-перезагрузкой)
npm run bot-dev
```

## 🎯 Что работает:

### ✅ Команды бота
- `/start` - Главное меню
- `/help` - Справка
- `/delivery` - Расчет доставки (заглушка)
- `/admin` - Админ-панель (заглушка)
- `/test` - Тестовый режим

### ✅ Типы сообщений
- Текстовые сообщения
- Фото, видео, документы
- Аудио, голосовые сообщения
- Стикеры
- Геолокация
- Контакты
- Опросы

### ✅ Кнопки
- Inline кнопки
- Reply кнопки
- Callback обработка

### ✅ Архитектура
- Core компоненты (Bot, DatabaseManager, SessionManager, StateManager)
- Сервисы (AuthService, MessageService, ButtonService, UserService, DeliveryService)
- Обработчики (MessageHandler, CallbackHandler, CommandHandler, DeliveryHandler)
- Адаптеры (PostgreSQL, Redis, 5 служб доставки)
- Middleware (AuthMiddleware)
- Система ролей и разрешений

## 🔧 Заглушки активированы для:

- **Базы данных** - PostgreSQL и Redis не требуются
- **Службы доставки** - СДЭК, Почта России, Деловые Линии, ПЭК, Байкал
- **Внешние API** - все интеграции работают в mock режиме

## 🐛 Если что-то не работает:

1. **Проверьте токен бота** в `.env` файле
2. **Убедитесь**, что токен правильный и бот не заблокирован
3. **Проверьте консоль** на наличие ошибок
4. **Запустите `/test`** для проверки компонентов

## 🔄 Замена заглушек на реальную реализацию:

Когда будете готовы к реальной интеграции:

1. **Настройте PostgreSQL** и замените заглушки в `DatabaseManager`
2. **Настройте Redis** для сессий и кэширования
3. **Замените заглушки** в адаптерах служб доставки на реальные API
4. **Добавьте реальные API ключи** в `.env`
