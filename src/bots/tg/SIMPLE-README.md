# Telegram Bot - Упрощенная версия с заглушками

## 🚀 Быстрый старт

Эта версия бота полностью готова к запуску и тестированию. Все компоненты работают с заглушками.

### 1. Установка зависимостей

```bash
npm install pg redis ioredis uuid winston joi @types/pg @types/redis @types/uuid @types/winston
```

### 2. Настройка переменных окружения

Создайте файл `.env` с минимальными настройками:

```env
# Telegram Bot (обязательно)
TG_BOT_TOKEN=your_telegram_bot_token

# Опционально (для заглушек не нужны)
# PG_HOST=localhost
# REDIS_HOST=localhost
```

### 3. Запуск бота

```bash
# Упрощенная версия с заглушками
ts-node src/bots/tg/simple-index.ts
```

## 🔄 Замена заглушек на реальную реализацию

Когда будете готовы к реальной интеграции:

### 1. Базы данных
Замените заглушки в `adapters/database/` на реальное подключение к PostgreSQL и Redis.

### 2. Службы доставки
Замените заглушки в `adapters/delivery/` на реальные API интеграции.

### 3. Внешние сервисы
Добавьте реальные API ключи в `.env` файл.

### 4. Миграция на полную версию
Когда все заглушки будут заменены, переключитесь на `new-index.ts`.

## 🐛 Устранение проблем

### Бот не запускается
1. Проверьте токен бота в `.env`
2. Убедитесь, что все зависимости установлены
3. Проверьте права доступа к файлам

### Ошибки TypeScript
1. Запустите `npm install` для установки всех зависимостей
2. Проверьте версию Node.js (рекомендуется 18+)

### Нет ответа от бота
1. Проверьте, что бот запущен без ошибок
2. Убедитесь, что токен правильный
3. Проверьте консоль на наличие ошибок
